# Redlet

本地运行的图文发布工作流。先支持小红书创作平台，读取明确的文案和图片，自动填写预览，并逐步完善提交与结果记录。

**状态：文档与设计阶段。** 浏览器适配器尚未实现。项目采用 Apache-2.0 许可证。

GitHub 仓库名：`redlet`。产品名称与未来命令名：`Redlet` / `redlet`。

## 为什么做

发布开发笔记时，正文分段、本地图片上传、AI 内容声明和提交结果核对会反复占用时间。这个项目把这些固定操作收进一个可复用的工具。

已有类似开源项目。本项目从明确的本地发布包、可审阅预览和防重复结果记录入手；现有实现可作为候选依赖或技术参考，不宣称首创小红书自动化。

## 首个里程碑

- 读取独立 JSON 发布包，公开正文与工程备注分别保存。
- 在专用浏览器环境核对账号，填入标题和多段正文。
- 上传明确指定的本地图片，核对数量和顺序。
- 设置适用的 AI 内容声明及可见范围。
- 回读并保存本篇预览结果，首轮停在提交之前。

后续实现提交与结果回写：同一内容 ID 防重复，提交、待核对、已发布分别记录；未知结果先核对，不自动重发。结果查询只针对本篇。

## 实现方向

候选：Node.js / TypeScript 与浏览器自动化适配器。先验证已有小红书 MCP 是否适用，关键缺口较大时采用薄的 Playwright 适配器。CLI 是首个入口，MCP 包装可后续添加。

运行会话、浏览器配置和真实发布数据保留在本地运行目录，不作为仓库素材。开发与演示使用普通编辑示例。
