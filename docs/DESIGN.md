# 初始设计范围

2026-10-23。首版已实现素材读取、独立浏览器登录、填写及回读预览；Rednote 两图示例已通过实际验收。具体证据见 VERIFICATION.md。

## 目标

将明确的标题、正文、图片及设置转为可回读的本地发布预览，减少临时桌面点击。首个场景是独立开发者的低频小红书制作笔记。

## 首版闭环

输入为独立发布包：content_id、title、body、图片列表、AI 声明要求和可见范围。校验素材与内容 ID，公开正文不从内部交接全文中提取。

首次人工登录专用浏览器环境，后续复用可用会话。程序核对账号后填写标题和正文、上传图片、设置 AI 声明与公开范围。首个验证停在预览，不提交公开测试帖。

验收逐项核对标题、多段正文、图片顺序与数量、AI 声明和可见范围。回读不一致时明确失败。模拟测试与实际页面预览分别记录。

## 发布与结果

后续添加最终提交和状态回写。同一 content_id 在本地防重复；已提交、待核对、已发布和失败分别保存。提交结果不明时只查询本篇，不能自动重发。优先使用平台真实返回的笔记标识或链接；缺失则留空，不能虚构。

## 执行适配器

采用 Node.js / TypeScript 与薄的 Playwright 适配器。已检查上游 Go 与 Python 路径，复用其页面步骤和定位线索；填写、图片摘要、账号与设置回读独立实现。调研见 REUSE_RESEARCH.md。首版提供 CLI，MCP 包装后续再考虑。

需要在当前账号实际可用的创作平台验证，不默认国内与海外入口完全一致。对页面的交互采用正常发布流程，不逆向签名或直接依赖未公开发帖接口。

## 内容范围

只读取明确提供的发布包、图片和本次任务结果；不以其他私人笔记、私人浏览标签、会话文件或个人材料作为内容背景。预览图只保留必要的项目区域。

首轮不扩展账号矩阵、自动评论、私信、内容抓取、多平台分发或云端常驻。

## 公开开发

记录实际完成、失败和取舍，用通用示例演示。运行文件不入仓库；不把计划写成已实现，不把工程验证写成真实用户效果。完整公开范围与许可证在远程发布前明确。
