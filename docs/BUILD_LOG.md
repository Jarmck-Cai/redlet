# 制作记录

## 2026-10-23：先把流程收成一个项目

从日常图文发布中遇到的分段、上传、AI 声明和回执问题出发，决定单独整理一个本地工具。

今天完成的是立项范围、本地 Git 仓库和 GitHub 公开仓库。第一步先让一份文案和图片自动填好预览，逐项核对后停住。浏览器适配器、真实页面验收与最终提交都尚未实现。

已有开源实现可以参考。接下来先检查其适用程度，再决定复用哪一层；开发记录会保留这些实际选择。

名称确定为 Redlet，仓库名 redlet；许可证采用 Apache-2.0。公开仓库：https://github.com/Jarmck-Cai/redlet 。浏览器预览适配仍待实现。
