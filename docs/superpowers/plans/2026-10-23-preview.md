# Redlet preview Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Read a local post bundle and prepare a verified Xiaohongshu/Rednote editor preview, stopping before final submission.
**Architecture:** A bundle reader resolves only explicit package assets. A thin Playwright adapter fills the real editor and reads it back. The CLI owns a dedicated persistent Chrome profile and local receipts.
**Tech Stack:** Node.js >=20, TypeScript, Playwright, node:test through tsx.
**Spec:** ../../DESIGN.md; user explicitly requested implementation and testing on 2026-10-23.

## Global Constraints
- 首个验证停在预览，不提交公开测试帖。
- Only explicit bundle assets; profile and receipts stay in ignored .runtime/.
- Existing history remains; future commits use the repository-configured author email.
- Uploading a preview sends specified images to the platform and may create an automatic draft.

## Review Focus
- Preserve blank lines, literal HTML characters and Unicode in body text.
- Missing, duplicated, oversized or escaping assets fail before opening a browser.
- Login expired, ambiguous/mismatched account or nonempty editor: stop before editing.
- Upload count/order and text/settings must be read back, not inferred from clicks.
- Preview never invokes submission; uncertain verification is reported as failed.
